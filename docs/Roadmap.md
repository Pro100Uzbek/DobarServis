Четкий план реализации проекта (Roadmap)
Этап 1: Очистка кода и Core Web Vitals (Неделя 1)
Tailwind CDN: Переход на локальную сборку через @tailwindcss/vite для обнуления Total Blocking Time (TBT).
Статические иконки: Замена 43 клиентских иконок Lucide на inline SVG-компоненты. Это уберет ~30 КБ JS из главного потока.
Оптимизация медиа: Внедрение встроенного компонента <Picture> из astro:assets для автоматической генерации AVIF/WebP. 
Установка fetchpriority="high" для Hero-баннера, чтобы ускорить Largest Contentful Paint (LCP).
Чистые URL и редиректы: Удаление .html на уровне сборки Astro и настройка файла _redirects для Cloudflare/GitHub Pages, чтобы не потерять накопленный ссылочный вес.
CI/CD пайплайн: Обновление deploy.yml с добавлением кэширования npm и обязательного шага astro check для отлова TypeScript-ошибок перед деплоем.

Этап 2: SEO-монолит и Мультиязычность (Неделя 2)
Единый SEO-контракт: Создание интерфейса seo.ts для централизованного управления тегами canonical, hreflang и x-default.   
Связанный JSON-LD: Динамическая генерация микроразметки, где Service и BreadcrumbList жестко ссылаются на единый @id корневой сущности LocalBusiness.   
Контекстная маршрутизация: Переработка ContactModal.astro. 
Чтение атрибутов data-lang и data-city напрямую из DOM для формирования корректных ссылок-переходов в WhatsApp и Telegram без жесткого хардкода в JS.   

Этап 3: Контентная фабрика pSEO (Неделя 3)
Astro Content Collections: Подключение Zod-схем для строгой типизации генерируемого контента (услуги, города, бренды).   
Безопасная генерация страниц: Сборка страниц «Услуга × Город × Бренд» с уникализацией контента (динамические Title, Meta Description, специфичные блоки симптомов поломок), 
чтобы избежать пессимизации поисковиками.
Динамический Sitemap: Интеграция @astrojs/sitemap с фильтрацией служебных страниц (404, privacy) и автоматическим учетом всех новых локализованных URL.   

Этап 4: Автоматизация бизнеса «Uber для мастеров» (Неделя 4+)
Омниканальная шина (n8n): Сводка всех лидов (формы сайта, WhatsApp, Telegram-боты, звонки) в единый стандартизированный поток.
База данных (Supabase): Развертывание PostgreSQL для хранения справочника мастеров (география, компетенции, статус), истории заказов и расчета финансовых комиссий.
Диспетчеризация (Telegram): Запуск закрытого Telegram-бота, который транслирует заявки профильным мастерам в их регионе. 
Реализация кнопок «Взять заказ» и «Завершить» с прикреплением чека для автоматического биллинга.
